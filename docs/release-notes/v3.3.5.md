# v3.3.5 — streamed DSML tool-call fix

- Keep partial DSML tool-call prefixes buffered when they arrive across stream chunks, preventing stray `<` characters and trailing wrapper tags from leaking into response text.
- Add regression coverage for tokenized DSML tool calls and ordinary text containing `<` and `|`.
