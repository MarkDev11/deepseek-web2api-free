# v3.3.6 — 客户端 API Key 管理与账号池配置统一

v3.3.6 汇总四个候选版本的改进，重点完善了客户端 API Key 管理、启动体验和账号配置方式。

## 新增

- **WebUI 客户端 API Key 管理**：可创建多个 Key、查看 Key 前缀和创建时间，并单独撤销 Key。完整 Key 仅在创建时显示一次；服务端仅保存 SHA-256 哈希。
- **旧 Key 一次性导入**：首次初始化 Key 数据库时，可从 `.env` 中导入旧版 `API_KEYS` / `DEEPSEEK_API_KEY` 配置。

## 改进

- 启动信息现在会在同一行显示管理密码标签及当前生效值；系统环境变量覆盖 `.env` 时显示覆盖后的值，未配置时显示默认值 `admin`。
- Windows 启动脚本会在 `.env` 不存在时从 `.env.example` 创建配置文件。
- WebUI 构建脚本会先检查 `tsc`、`vite`；依赖安装失败或构建工具缺失时明确报错退出。有 `package-lock.json` 时使用 `npm ci`，并提示检查 registry 或代理连接。
- GitHub Release 工作流会将带连字符的版本标签（如 `v3.3.6-rc.1`）标记为预发布版本。

## 账号配置变更

- 账号凭证统一通过 WebUI 账号池或 `data/accounts.json` 配置；不再从 `.env` 读取旧版 `DEEPSEEK_TOKEN`、`DEEPSEEK_COOKIES`、`DEEPSEEK_EMAIL` 及编号式账号变量，也不再提供 `.env` 账号兜底或逐账号代理配置。
- 账号池为空时服务不会尝试使用环境变量中的凭证，并会提示如何添加账号。
- WebUI 移除了环境变量账号的只读状态和来源统计；`.env.example`、中英文 README 和维护文档已同步。

> **升级提醒：** 如果此前把 DeepSeek 账号凭证放在 `.env`，升级前请将账号迁移至 WebUI「账号池」或 `data/accounts.json`。旧客户端 API Key 会在数据库首次初始化时导入一次；请确认初始化成功后再移除旧配置。客户端 Key 的明文不会在之后再次显示，请在创建时妥善保存。
